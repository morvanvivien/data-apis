KissKissBankBank Crowdfunding Projects

French crowdfunding projects from KissKissBankBank, one of Europe's main crowdfunding platforms (a French Kickstarter alternative), as clean JSON: title, short description, categories, city, country, state (live or successful), amount collected, goal, funding percentage, number of backers, start and end dates and duration. For crowdfunding market research, startup and maker scouting, and trend analysis in France and Europe. Public pages only, no backer data. Backed by the Apify Actor bibian/kisskissbankbank-projects-scraper.

Good for: crowdfunding API, Kickstarter alternative data for France and Europe, financement participatif, startup and maker scouting, success rate and funding benchmarks per category, trend analysis for food, design, music, film and social projects.

Where to get it

  • RapidAPI
  • Apify Actor
  • Source on GitHub

Example request

curl -X POST "https://kisskissbankbank-crowdfunding-projects.p.rapidapi.com/v2/acts/bibian~kisskissbankbank-projects-scraper/run-sync-get-dataset-items?clean=true" \
  -H "x-rapidapi-key: <YOUR_RAPIDAPI_KEY>" \
  -H "x-rapidapi-host: kisskissbankbank-crowdfunding-projects.p.rapidapi.com" \
  -H "content-type: application/json" \
  -d '{"maxItems":50}'

The response is a JSON array. The same call works from any language that can send an HTTP POST. A call can take several seconds because the data is read live.
