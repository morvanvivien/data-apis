AlloCine Movies France

French cinema data from AlloCiné (allocine.fr), France's leading movie site, as clean JSON: movies now playing in French theaters, this week's releases or the most awaited upcoming films, with release date, runtime, genres, directors, cast, press and audience ratings, number of showtimes across France, synopsis and poster. For box office trackers, movie apps, chatbots and French market research. Public pages only. Backed by the Apify Actor bibian/allocine-movies-scraper.

Good for: France movies API, French cinema and box office data, films à l'affiche and sorties de la semaine, showtimes coverage per film, movie apps, chatbots and recommendation engines for France.

Where to get it

  • RapidAPI
  • Apify Actor
  • Source on GitHub

Example request

curl -X POST "https://allocine-movies-france.p.rapidapi.com/v2/acts/bibian~allocine-movies-scraper/run-sync-get-dataset-items?clean=true" \
  -H "x-rapidapi-key: <YOUR_RAPIDAPI_KEY>" \
  -H "x-rapidapi-host: allocine-movies-france.p.rapidapi.com" \
  -H "content-type: application/json" \
  -d '{"list":"now-playing","maxItems":50}'

The response is a JSON array. The same call works from any language that can send an HTTP POST. A call can take several seconds because the data is read live.
