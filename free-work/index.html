Free-Work Jobs API

French IT jobs and freelance missions from free-work.com, the leading French tech job board, as clean JSON: title, company, daily rate (TJM) or salary, skills, remote mode, location, dates and full description. One call returns the matching postings. Public pages only, no personal data, robots.txt respected. Backed by the Apify Actor bibian/free-work-jobs-scraper.

Good for: France jobs API, French IT job board data, freelance missions in France (missions freelance, TJM, régie), tech salary benchmarks in France, job alerts for Paris, Lyon, Toulouse, Nantes, Lille and remote.

Example request

curl -X POST "https://free-work-jobs.p.rapidapi.com/v2/acts/bibian~free-work-jobs-scraper/run-sync-get-dataset-items?clean=true" \
  -H "x-rapidapi-key: <YOUR_RAPIDAPI_KEY>" \
  -H "x-rapidapi-host: free-work-jobs.p.rapidapi.com" \
  -H "content-type: application/json" \
  -d '{"keywords":"data engineer","contracts":["contractor"],"publishedWithinDays":7,"maxItems":50,"includeDescriptions":false}'

The response is a JSON array. The same call works from any language that can send an HTTP POST. A call can take several seconds because the data is read live.
