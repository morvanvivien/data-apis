Spain Jobs Infoempleo

Spanish job postings from Infoempleo (infoempleo.com), one of Spain's main job boards, as clean JSON: title, occupation, industry, company, city, region, salary range, experience, working hours, employment type, dates and full description. One call returns the matching postings. No login, no personal data. Backed by the Apify Actor bibian/infoempleo-jobs-scraper.

Good for: Spain jobs API, Spanish job board data, ofertas de trabajo y empleo en España, salary benchmarks in Spain, job alerts for Madrid, Barcelona, Valencia, Sevilla, Málaga and Bilbao.

Example request

curl -X POST "https://spain-jobs-infoempleo.p.rapidapi.com/v2/acts/bibian~infoempleo-jobs-scraper/run-sync-get-dataset-items?clean=true" \
  -H "x-rapidapi-key: <YOUR_RAPIDAPI_KEY>" \
  -H "x-rapidapi-host: spain-jobs-infoempleo.p.rapidapi.com" \
  -H "content-type: application/json" \
  -d '{"keywords":"programador","location":"Madrid","publishedWithin":"7","maxItems":50,"includeDescriptions":true}'

The response is a JSON array. The same call works from any language that can send an HTTP POST. A call can take several seconds because the data is read live.
