Codeur Freelance Projects France

French freelance projects and missions from Codeur.com, the leading French freelance marketplace for developers, designers and marketers, as clean JSON: title, status, budget, number of offers and views, category, wanted profiles, publication date and the client's full brief. Track new French freelance missions, measure demand per skill (WordPress, React, SEO...) or feed a freelancer alert. Public pages only, no personal data. Backed by the Apify Actor bibian/codeur-projects-scraper.

Good for: France freelance jobs API, French freelance marketplace data, missions freelance and appels d'offres for developers, WordPress, React, SEO and design, demand per skill in France, daily alerts of new freelance missions.

Example request

curl -X POST "https://codeur-freelance-projects-france.p.rapidapi.com/v2/acts/bibian~codeur-projects-scraper/run-sync-get-dataset-items?clean=true" \
  -H "x-rapidapi-key: <YOUR_RAPIDAPI_KEY>" \
  -H "x-rapidapi-host: codeur-freelance-projects-france.p.rapidapi.com" \
  -H "content-type: application/json" \
  -d '{"keywords":"wordpress","publishedWithinDays":14,"onlyOpen":true,"maxItems":20,"includeDescription":true}'

The response is a JSON array. The same call works from any language that can send an HTTP POST. A call can take several seconds because the data is read live.
