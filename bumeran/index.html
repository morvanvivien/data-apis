LatAm Jobs Bumeran Zonajobs Laborum

Job postings from Bumeran, Zonajobs, Laborum, Multitrabajos and Konzerta (Argentina, Chile, Peru, Ecuador, Panama, Venezuela) as clean JSON in one call: title, company, location, work type, work mode, vacancies, dates and full description. No login, no personal data. Backed by the Apify Actor bibian/latam-jobs-bumeran-scraper.

Good for: Argentina jobs API, Chile jobs API, Peru jobs API, Ecuador jobs API, LatAm job board data, empleos y trabajos en Buenos Aires, Córdoba, Santiago, Lima, Quito and Panamá, job alerts and hiring trends in Latin America.

Example request

curl -X POST "https://latam-jobs-bumeran-zonajobs-laborum.p.rapidapi.com/v2/acts/bibian~latam-jobs-bumeran-scraper/run-sync-get-dataset-items?clean=true" \
  -H "x-rapidapi-key: <YOUR_RAPIDAPI_KEY>" \
  -H "x-rapidapi-host: latam-jobs-bumeran-zonajobs-laborum.p.rapidapi.com" \
  -H "content-type: application/json" \
  -d '{"countries":["argentina"],"keywords":"desarrollador","publishedWithinDays":7,"maxItems":50,"includeDescriptions":true}'

The response is a JSON array. The same call works from any language that can send an HTTP POST. A call can take several seconds because the data is read live.
