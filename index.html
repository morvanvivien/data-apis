Job and data APIs for France, Germany, Spain and Latin America

Seven REST APIs that return public job postings, freelance missions, films and crowdfunding projects as clean JSON. Sold on RapidAPI and Zyla API Hub, also available as Apify Actors.

Free-Work Jobs API

France IT jobs API: French tech jobs and freelance missions from Free-Work (free-work.com) as JSON, with daily rate (TJM), salary, skills, remote mode, location and full description.

RapidAPI · Zyla API Hub · Apify Actor

German Jobs Arbeitsagentur

Germany jobs API: job postings (Stellenangebote) from the Bundesagentur für Arbeit Jobsuche (arbeitsagentur.de), Deutschland's largest job database, as JSON with salary, home office and location.

RapidAPI · Zyla API Hub · Apify Actor

Spain Jobs Infoempleo

Spain jobs API: Spanish job postings (ofertas de empleo) from Infoempleo (infoempleo.com) as JSON, with salary range, company, city, region, experience, contract type and description.

RapidAPI · Zyla API Hub · Apify Actor

LatAm Jobs Bumeran Zonajobs Laborum

Latin America jobs API: postings (ofertas de empleo) from Bumeran, Zonajobs, Laborum, Multitrabajos and Konzerta for Argentina, Chile, Peru, Ecuador, Panama and Venezuela, as JSON.

RapidAPI · Zyla API Hub · Apify Actor

Codeur Freelance Projects France

France freelance jobs API: freelance projects and missions from Codeur.com as JSON, with budget, offers, views, category, wanted profiles, date and the client's full brief.

RapidAPI · Zyla API Hub · Apify Actor

AlloCine Movies France

France movies API: films now playing in French cinemas, this week's releases and upcoming movies from AlloCine as JSON, with ratings, showtimes count, cast and synopsis.

RapidAPI · Apify Actor · Source on GitHub

KissKissBankBank Crowdfunding Projects

Crowdfunding API for France and Europe: KissKissBankBank projects as JSON, with amount collected, goal, funding percentage, backers, category, city and dates.

RapidAPI · Apify Actor · Source on GitHub

Independent project by Vivien Morvan, not affiliated with or endorsed by the websites mentioned. The APIs read publicly visible pages only, with no login and no personal data, and respect robots.txt.
